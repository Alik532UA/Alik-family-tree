# Alik-family-tree 🌳

Інтерактивний веб-сайт родинного генеалогічного древа родини Запольнових, Булатів, Соколовських, Кульчицьких, Миндру та споріднених гілок.

Побудований за стандартами **`sveltekit-canon` v10** (`selection_criteria/v10` та `product_criteria/v10`).

## 🌟 Основні можливості

- **Інтерактивне векторне полотно (21360 × 2143 px):**
  - Плавне панорамування та масштабування (drag-to-pan, wheel zoom, pinch-to-zoom на сенсорних екранах).
  - Підсвітка та виділення вибраної персони з анімованим контуром.
  - Динамічні зв'язки (батьки, подружжя, діти) зі стрілками та анімацією ліній спорідненості.
- **Інтерактивна мінімапа (MINIMAP):**
  - Повноформатний огляд полотна з живим індикатором зони видимості.
  - Миттєвий перехід у будь-яку точку древа в один клік.
- **Шкала поколінь (Timeline):**
  - 8 поколінь родини від засновника роду Алентія Запольнова (поч. XIX ст.) до сучасного покоління (Алік Запольнов).
  - Швидка навігація між поколіннями та часовими віхами (включаючи лінію 1975 року).
- **Миттєвий пошук родичів (гаряча клавіша `/`):**
  - Пошук за ім'ям, прізвищем, дівочим прізвищем, гілкою або поколінням.
  - Автодоповнення з фокусуванням та центруванням на обраній особі.
- **Детальна картка персони (Drawer):**
  - Повне ім'я, дівоче прізвище, покоління, стать, фамільна гілка.
  - Клікабельні картки батьків, дітей, подружжя та братів/сестер.
  - Пряме посилання на персону (`#person-<id>`) з копіюванням у буфер.
- **Розумна приватність (Family PIN):**
  - Захист чутливих даних нині живих родичів.
  - Можливість розблокування доступу для членів родини за секретним родинним кодом.
- **Повноцінний каталог (`/directory`) та статистика (`/stats`):**
  - Алфавітний каталог із фільтрами за гілками та поколіннями.
  - Аналітика за гілками, демографією та найдавнішими предками.
- **Продуктовий канон родини сайтів:**
  - Фірмовий перемикач тем із попереднім переглядом при наведенні (Світла, Темна, Сепія, Поляна, Небесна).
  - Кастомний скролбар із контекстним меню налаштувань.
  - Тости сповіщень із таймером та паузою при наведенні.
  - Кнопка повного екрана.

## 🛠️ Технічний стек

- **Фреймворк:** SvelteKit 2 + Svelte 5 (Runes)
- **Профіль:** Static (`@sveltejs/adapter-static`)
- **Типізація:** TypeScript (суворий режим, `noUncheckedIndexedAccess`, `noImplicitReturns`)
- **Тестування:** Vitest
- **Лінтинг:** ESLint 9 (Flat Config), Prettier
- **Іконки:** Lucide Icons (SVG)

## 🚀 Запуск та розробка

```bash
# Встановлення залежностей

# Запуск dev-сервера
npm run dev

# Перевірка типів
npm run check

# Запуск тестів
npm run test:unit

# Збірка статичного сайту
npm run build
```
