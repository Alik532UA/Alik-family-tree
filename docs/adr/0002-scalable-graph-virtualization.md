# ADR 0002: Архітектура масштабування родинного графа та віртуалізації в'юпорту

## Контекст

При зростанні родинного дерева до тисяч осіб клієнтський рендеринг повного дерева в SVG може спричиняти падіння FPS через надмірну кількість DOM/SVG-вузлів.

## Рішення

1. **Індекс швидкого пошуку (`FastPersonIndex`)**: Токенізований пошуковий індекс у пам'яті (`$lib/services/searchIndex.ts`) забезпечує пошук за підрядками, дівочими прізвищами та роками народження за < 2мс для баз до 50 000 осіб без блокування UI.
2. **Відсікання за межами в'юпорту (`cullNodesOutOfViewport`)**: Обчислюється перетин обмежувального прямокутника вузла зі світовими координатами екрану з запасом поля 200px. Вузли поза полем зору не рендеряться в активному дереві.
3. **Захист від колізій сховища**: Усі кешовані вибірки зберігаються з суворим префіксом `aft_`.
